Entry for the [make.fun](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b) bounty "The Internet in One Word".

One word for the whole internet: **doomscroll** — funny on its own, true about the whole internet, surprising next to the obvious picks, and it lands in one beat.

`main.ts` writes the entry to `/output/entry.txt` and validates it against the gate (1–30 characters, not only white space, exactly one word), then reads it back byte-for-byte.
